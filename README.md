# Guerrilla Picture Factory — Sequence File Renamer

A self-contained browser app for previewing and creating sequentially named copies of selected files. The original files are never changed.

## Host it with GitHub Pages

1. Create a GitHub repository and upload all files in this folder to the repository root: `index.html`, `favicon.png`, `apple-touch-icon.png`, `app-icon.png`, `site.webmanifest`, and this `README.md`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select your main branch and the root (`/`) folder.
4. Save. GitHub Pages looks for `index.html` at the publishing source and publishes it as the site entry point. See [GitHub's Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

The site is public. File selection, preview, sequencing, and PNG conversion happen in the visitor's browser; selected files are not uploaded to GitHub by this app. Presets are saved in each visitor's browser.

## Put it on your Mac desktop

After GitHub Pages gives your site a URL, open it in Safari on your Mac. Choose **File → Add to Dock** (or **Share → Add to Dock**) and add the web app. Safari puts it in the Dock and your home Applications folder, using the aperture icon supplied here. If you want it on the desktop itself, open your home Applications folder in Finder, right-click the new app, choose **Make Alias**, then drag the alias to your desktop. Apple documents the Add to Dock feature [here](https://support.apple.com/guide/safari/ibrw9e991864/mac).

GitHub Pages hosts the app but does not charge visitors. To sell access or downloads, link the site to a separate checkout and delivery service.
